# Contributing

Thanks for helping make the Singapore Showdown more accurate, surprising and fun.

## Suggesting a question

Use the **Question suggestion** issue template. Please include:

- the proposed question;
- four plausible options;
- the correct answer;
- a short explanation; and
- a reliable source, preferably an official or primary source.

## Correcting a question

Use the **Question correction** issue template and identify the round and question text. Explain what is wrong and provide a source supporting the correction.

## Pull requests

Before opening a pull request:

```bash
npm ci
npm run validate
npm run build
```

Keep questions concise enough to read aloud and avoid ambiguous answers, stereotypes and unsupported “fun facts.”
